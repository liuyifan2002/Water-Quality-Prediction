# 作者最终填写事项清单

本清单依据当前整合稿中的实际占位内容编制。本轮未编造个人信息，未撰写或替代学校正式声明；以下内容完成前，论文仍是供作者核定的排版修订稿。

|页面|作者须提供或确认的信息|需要的学校材料与操作|
|---|---|---|
|封面|姓名、学号、学位类别、学科专业、研究方向、指导教师姓名及模板要求的职称、实际完成日期；分类号、密级及保密信息按学院要求确认。论文题名保持当前确认版本，学校代码10386沿用原稿，提交前核对。|研究生院或学院当前适用的硕士学位论文封面模板；如需英文封面，提供正式英文姓名、专业及题名写法。不得自行猜测学位类别、密级或导师职称。|
|学术行为规范承诺|本人真实签名、签署日期，及模板明确要求的其他身份字段。|提供学校正式《遵守学术行为规范承诺》文本及签名页，完整替换现有“待按模板插入”提示；是否使用电子签名按学校要求办理。|
|独创性声明|作者及导师真实签名、实际签署日期。|提供学校当前正式独创性声明页，保留原有正式措辞，不用本稿占位说明代替。|
|论文使用授权说明|作者、导师签名与日期；公开或保密选项；若属保密论文，确认批准文件、保密期限及解密年份。|提供学校正式授权说明和保密选项模板，由作者与导师据实际情况选择，不能默认勾选或推算解密年份。|
|个人简历|真实教育经历及起止年月、学校、专业、学位等模板要求的内容；其他个人信息仅按学校模板需要填写。|提供学院要求的简历格式，替换“待作者填写”提示。不自行补写出生信息、经历或任职。|
|在学期间研究成果及发表论文|已发表、已录用或正式登记的真实成果；论文题名、完整作者顺序及本人位置、期刊/会议、年份卷期页码、DOI或可核验记录；已录用须提供录用依据。项目、专利、奖励等仅列真实参与且符合学校收录要求的项目。|提供学院成果填写规范及相应证明材料；如确无可列成果，由作者按学校要求决定注明方式，不能编造或将投稿写作录用。|

作者完成上述页面后，还需：

1. 删除被正式材料替换的占位说明和空白下划线，核对题名、姓名、学号、导师及日期前后一致。
2. 确认正式声明、授权和签名页的实际签署要求，检查保密选项与批准材料一致。
3. 在Word中更新目录、图目录、表目录及所有域，重新导出PDF。行政材料的长度变化会改变后续页码，不能直接沿用本次检查页码。
4. 核对最终PDF中签名、表头重复、分页和图注，保留已确认的图像、实验结果与参考文献。

本轮不要求作者补做模型、预测或解释实验；上一轮已披露的科研数据缺口保持原状。
