# 候选模型稳健性验证结论

## 1. 运行完整性

- 回传包包含随机三种子、2014-2022 年训练至 2023-2024 年测试、五折留站点三类验证。
- 共完成 189 个模型任务：随机种子 63 个、年份留出 21 个、五折留站点 105 个。
- 全部任务成功，无错误、无缺失结果。
- 每一个候选模型均与同一划分、同一特征集、同一目标变换下的 XGBoost 比较。同期水质协变量未进入输入；年份留出和留站点均排除了目标自身历史特征。

## 2. 总体判断

- **TabM 不进入中长期候选模型。** 它在随机种子和多数留站点折次中有增益，但七项任务的年份留出 R2 均低于 XGBoost，不能支持其用于跨年份预测。
- **TabPFN 保留为四项任务的扩展候选。** Chl-a 表层、透明度表层、透明度底层和 TN 底层在随机种子、留站点和年份留出三种验证中均高于 XGBoost。
- **其余三项不作明确推广。** Chl-a 中层、Chl-a 底层和透明度中层在随机种子与留站点中稳定提高，但年份留出变化为 -0.0015、-0.0015 和 -0.0002，实质接近持平，尚不能称为跨年份提升。
- 所有模型在年份留出中均明显低于随机留出，表明当前主要瓶颈仍是跨年份过程变化，不是单纯更换算法可以消除的。

## 3. TabPFN 的可保留任务

| 任务 | 随机三种子 R2：XGBoost -> TabPFN | 五折留站点 R2：XGBoost -> TabPFN | 年份留出 R2：XGBoost -> TabPFN | 结论 |
|---|---:|---:|---:|---|
| Chl-a 表层 | 0.4331 -> 0.5800（+0.1469） | 0.4274 -> 0.5511（+0.1236） | 0.1782 -> 0.2174（+0.0391） | 保留 |
| 透明度表层 | 0.6101 -> 0.6531（+0.0430） | 0.5099 -> 0.5673（+0.0574） | 0.4204 -> 0.4289（+0.0085） | 保留 |
| 透明度底层 | 0.5553 -> 0.6008（+0.0455） | 0.5183 -> 0.6047（+0.0864） | 0.3807 -> 0.4017（+0.0210） | 保留 |
| TN 底层 | 0.6144 -> 0.6728（+0.0584） | 0.5032 -> 0.6079（+0.1047） | 0.1820 -> 0.2150（+0.0330） | 保留 |

透明度原始观测在三水层中存在重复记录。因此表层、中层、底层的透明度模型结果只能作为同一站点-日期透明度的重复建模检验，不能在论文中当作三类独立实测证据。

## 4. 暂不推广的任务

| 任务 | TabPFN 在年份留出中的 R2 变化 | 原因 |
|---|---:|---|
| Chl-a 中层 | -0.0015 | 随机和空间检验有增益，但跨年份未提高。 |
| Chl-a 底层 | -0.0015 | 同上。 |
| 透明度中层 | -0.0002 | 实质持平，不能写成中长期提升。 |

## 5. TabM 的定位

TabM 的随机种子平均增益为 +0.0363 至 +0.1455，留站点平均增益为 -0.0661 至 +0.1307；但年份留出七项全部为负变化（-0.0217 至 -0.1217）。它可在附录中作为“随机/空间条件下的算法对比”，但不作为本文中长期预测的推荐模型。

## 6. 论文写作口径

- 正式四指标主模型仍为现有 full_station XGBoost，不因本实验自动替换。
- TabPFN 可作为“候选表格预训练模型的稳健性对比”写入扩展实验。严格表述为：它在四个任务上同时改善随机、留站点和单次年份留出表现。
- 不能写成“TabPFN 普遍提高四指标三水层预测精度”，因为本实验没有覆盖 TP，且 Chl-a 中底层、透明度中层没有通过三类验证的一致性判定。
- 对 Chl-a 表层，TabPFN 是当前最有力的算法正信号；但其年份留出 R2 仍仅为 0.2174，研究结论应强调算法改善相对表现，而不应声称已解决跨年份藻华预测。

## 7. 后续动作

1. 保留 TabPFN 的四项候选结果，输出与 XGBoost 配对的散点图、R2 变化图和年份留出对比图。
2. 不再为 TabM 重复开展大规模调参或扩展任务实验。
3. Chl-a 中底层和透明度中层暂保持 XGBoost；后续只有在补充跨年份过程数据后，才值得重测 TabPFN。
4. TN 底层可将 TabPFN 作为补充结果，但其年份留出绝对 R2 仍低，不能将随机留出的 0.6728 写成中长期预测精度。
