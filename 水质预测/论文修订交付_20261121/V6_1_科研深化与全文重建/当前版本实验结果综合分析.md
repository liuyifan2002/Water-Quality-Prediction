# 当前版本实验结果综合分析

本报告只使用 `WQ77_REPAIRED_20261115_V1` 的冻结预测和候选版实验汇总；未训练或重新预测。站点聚类 Bootstrap 使用固定配对 `obs_id`、五折测试样本、1000 次有放回站点抽样、随机种子 20260921、百分位 95% 区间。该种子沿用 Chl-a/TN 家族汇总程序；旧 Secchi 单独审查曾用 42，故本表十任务统一采用 20260921。Δ 指标均为 TabICLv2 减 XGBoost，负 ΔRMSE/ΔMAE 表示误差降低。

## 六来源删组消融（XGBoost，四任务）

实验登记为四任务×六来源×五折，共 120 任务折；源组映射按冻结 taxonomy 哈希 `b8141c13...`，变量数量分别为 HUM 6、MET 29、OCN 11、RHT 22、SPA 2、TMP 7。ΔR²=删组模型减完整模型；负值表示删除后性能下降。该证据不等于单变量 SHAP 归因或环境因果效应。

| 任务 | 删除后性能下降的来源（ΔR²<0） | 删除后性能提高的来源（ΔR²>0） |
|---|---|---|
| chla_surface | SPATIAL_STATIC -0.072, OCEAN_PHYSICS -0.022, METEOROLOGY -0.012, RAINFALL_HYDRO_TIDE -0.007 | HUMAN_ACTIVITY +0.012, TEMPORAL_PROCESS +0.001 |
| secchi | SPATIAL_STATIC -0.113, METEOROLOGY -0.017, RAINFALL_HYDRO_TIDE -0.008, OCEAN_PHYSICS -0.008 | HUMAN_ACTIVITY +0.006, TEMPORAL_PROCESS +0.001 |
| tn_surface | HUMAN_ACTIVITY -0.016 | METEOROLOGY +0.020, RAINFALL_HYDRO_TIDE +0.012, TEMPORAL_PROCESS +0.007, OCEAN_PHYSICS +0.001, SPATIAL_STATIC +0.001 |
| tp_middle | METEOROLOGY -0.019, OCEAN_PHYSICS -0.001 | RAINFALL_HYDRO_TIDE +0.036, HUMAN_ACTIVITY +0.033, SPATIAL_STATIC +0.030, TEMPORAL_PROCESS +0.022 |

空间静态组在 Chl-a 表层和 Secchi 删组后 R² 分别下降 0.072 与 0.113；而在 TN 表层、TP 中层并未出现同方向同量级效应。TP 中层删去 RHT、HUM、SPA 后反而改善，说明特征组合在该任务下的泛化效用有限，不能推断原始来源具有负面环境作用。单来源删组无法识别来源间的交互或替代关系，互补性仅可作为待检验假说。

## 可复现性和限制

- 冻结逐折预测在配对前校验了 `obs_id`、站点、日期、折次、真实值和 manifest SHA256；10任务×2模型×5折均为当前版本。每站点的记录数不等，重抽样后指标按所抽站点的全部记录 pooled 计算。
- Bootstrap 的 95% 区间是站点抽样不确定性描述，不是因果检验；端点是否跨零见 CSV。
- 本轮未重新训练、预测、计算 SHAP/ALE 或修改冻结数据。
