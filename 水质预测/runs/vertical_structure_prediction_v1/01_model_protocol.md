# VSP-Net V1 实验协议

本实验为独立扩展实验，采用 WQ77_REPAIRED_20261115_V1 的77项strict特征、M1实验原有五折留站测试obs_id、验证站点选择规则、种子42/43/44及训练配置。M1预测直接读取 `runs/multitask_fttransformer_v1/predictions/`，不重新训练。V1/V2各训练5折×3种子；每折训练时从所有任务训练标签排除各任务测试站点并集，确保共享编码器不看到留出站点标签。站点ID和水区不进入模型输入。

数据为按水层存储的长表。`sample_id`标识同一采样事件，`obs_id`标识水层记录。同一事件各水层站点、日期一致；16个事件的 `days_since_prev_sample` 在水层间不同，因此保留三层各自的77项输入及缺失掩码，不进行平均、插值或任取某层替代。共享FT-Transformer分别编码各层输入，再以可用层表示形成事件表示；三个指标各有共享指标层和带水层嵌入的三层输出分支，Secchi仅有独立输出头。缺层输入通过层存在掩码排除事件汇总，缺失目标通过任务掩码排除损失。

V1完全使用M1的样本平均掩码MSE。V2仅增加权重固定0.1的垂向辅助损失：对Chl-a、TN、TP的表—中及中—底六组真实配对差值，逐组以该指标训练标签合并标准差标准化差值误差后计算Huber，再对六组等权平均。某组当前批次没有配对标签时贡献为零。训练集之外的真实目标值从不用于损失、预处理或早停。V1/V2都按M1原有验证集基础损失早停，测试集只做最终评价；推理仅使用各层允许的环境特征。

输出的pooled OOF R²为每个种子合并该任务五折测试预测后计算一次；fold mean R²为五折各自R²的算术平均。种子指标分别计算后取均值与标准差，不将三种子重复预测拼接。垂向差值评价只使用同一 `sample_id` 且两层真值、预测均存在的事件。Chl-a误差单位μg/L，TN/TP为mg/L，Secchi为m；不同指标的RMSE/MAE不跨单位求平均。
