## 2. 两个实验样本集

按 `obs_id` 与候选表一对一连接（`validate="one_to_one"`），并逐列核对 `sample_id` / `station` / `depth` 身份一致；不做站点+日期模糊拼接，不删除主表行，只在实验副本内筛选完整样本。

| 样本集 | 完整性条件 | 用途 |
|---|---|---|
| `paired_SB` | 4 项表底层差值非缺失 | 比较 M0 vs M1 |
| `complete_SMB` | 12 项三层原始值 + 4 项差值全部非缺失 | 主实验集，比较 M0–M3 |

逐任务实际样本数见 `01_十任务样本覆盖.csv`（不采用预设事件数，以真实记录为准）。候选表侧统计：三层四项齐全的采样事件 9,455 / 10,866；差值齐全 10,397 / 10,866。

## 3. 四种输入方案

| 方案 | 内容 | 特征数 |
|---|---|---:|
| M0 | 原始 WQ77 | 77 |
| M1 | WQ77 + ΔT / ΔS / ΔDO / Δρ₀ | 81 |
| M2 | WQ77 + 12 项三层原始值（温度/盐度/DO/浊度 × 表/中/底） | 89 |
| M3 | WQ77 + 12 项原始值 + 4 项差值 | 93 |

- 特征顺序：77 项冻结特征顺序原样保留，新增变量统一追加在尾部；完整清单见 `02_特征集清单.csv`。
- Δ 方向一律「表层 − 底层」；密度差为 **EOS-80 在 0 dbar 参考压力下**的密度差，不是原位压力下的真实密度差。
- 保留原始单位与正负方向，未做任何为提高精度的特征改写。
- 未加入同次采样的 Chl-a / TN / TP / Secchi 目标值；未使用 HYCOM、SCSORA；pH 未进入本轮。

## 4. 十项任务与样本角色

十个正式任务全覆盖（Chl-a / TN / TP × 表/中/底 + Secchi 独立）。每次运行：
先按 `depth == 目标层 & target.notna()` 取目标 `obs_id`，再按样本集完整性筛行，最后按冻结 manifest 赋予训练/测试角色。
M0–M3 在同一任务、同一模型下使用**完全相同的训练与测试 `obs_id` 集合**（已逐任务核验，见 `06_最终决策报告.md` §6）。

## 5. 模型与预处理（复用，不新增搜索）

| 项 | 设置 |
|---|---|
| 主模型 | TabICLv2（`models.tabiclv2_adapter.TabICLv2Regressor`，默认配置） |
| 对照模型 | XGBoost，参数取自 `结果/扩展实验/候选模型稳健性验证_20260914/portable_package/config.json`：`n_estimators=400, max_depth=4, learning_rate=0.05, subsample=0.8, colsample_bytree=0.8, n_jobs=4` |
| 随机种子 | 42（划分冻结，模型种子固定；本轮为单种子筛选） |
| 缺失填补 | 中位数 `SimpleImputer(keep_empty_features=True)`，**仅在训练集 fit** |
| 目标变换 | 训练集 y 最小值 ≥ 0 时 `log1p`，预测端 `expm1` 后截断至 ≥ 0 |
| 指标单位 | 原始水质单位（µg/L、m、mg/L）下计算 R² / RMSE / MAE |

未重新搜索超参数，未改目标变换，未重新生成任何划分。

## 6. 评价与决策

- 主比较：M1−M0、M2−M0、M3−M0、M3−M1、M3−M2，逐任务 ΔR² / ΔRMSE / ΔMAE。
- 汇总：十任务宏平均 R² 与宏平均 ΔR²；每任务训练/测试样本数与覆盖站点数。
- 区间：1000 次**配对站点 Bootstrap**（按 `station_id` 整群重抽，`seed=42`），95% 分位区间；配对前校验两侧 `obs_id` 与 `y_true` 完全一致。
- 决策门槛（研发投入标准，非统计显著性判定）：STRONG_PROMOTE = 宏平均 ΔR² ≥ 0.03 且 ≥5 项任务 ΔR² ≥ 0.02 且 ≥7 项任务不退化且 RMSE 无明显恶化；NO_PROMOTE = 宏平均 ΔR² < 0.01 或整体无实际改善。
