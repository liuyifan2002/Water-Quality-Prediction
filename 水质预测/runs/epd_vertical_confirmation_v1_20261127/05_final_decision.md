# EPD-Vertical V3 最终判定：89 项 M2 增强方案确认实验

日期：2026-11-27
实验目录：`runs/epd_vertical_confirmation_v1_20261127/`
方案：M0 = 冻结 WQ77（77 项）；M2 = WQ77 + 12 项 EPD 表/中/底层温度、盐度、DO、浊度（89 项）。样本集固定为 V2 的 `complete_SMB`。

> 协议纪律：阶段 A 为**冻结 Random Strict（随机比例留出，划分 seed=42，模型种子 42/2026/3407）**；阶段 B 为**五折 Station Holdout（留站点，OOF）**。两者数字分别计算、分别报告，不合并、不互相替代。

## 1. 结论

**判定：`CONFIRMED`。**

在三个模型随机种子下，M2 相对 M0 的十任务宏平均 ΔR² 分别为 +0.0843、+0.0911、+0.0898（三种子平均 **+0.0884**，跨种子标准差 0.0036）；在五折留站点协议下，pooled OOF 宏平均 ΔR² 为 **+0.0988**，十项任务全部为正。

- Random Strict：宏平均 R² 0.5512 → 0.6356（seed 42）、0.5487 → 0.6398（seed 2026）、0.5481 → 0.6380（seed 3407）。
- Station Holdout：宏平均 R² 0.4628 → 0.5615；留站点基线明显低于随机留出基线，M2 在更严格协议下仍全面优于 M0。
- 唯一低于材料性阈值（+0.02）的任务是 TN 表层：Random Strict 三种子平均仅 +0.0087，且 seed 42 为负（−0.0027）；但在留站点协议下 TN 表层 ΔR² 达 +0.0693 且区间不跨 0 —— **该任务是协议依赖的，不是稳定无感的**。

## 5. 两个验证协议的对比

| 任务 | Random Strict ΔR²（三种子均值） | Station Holdout ΔR²（pooled） | 方向一致 |
|---|---:|---:|---|
| Chl-a 表层 | 0.0875 | 0.0859 | 是 |
| Chl-a 中层 | 0.1147 | 0.1829 | 是 |
| Chl-a 底层 | 0.1246 | 0.1507 | 是 |
| Secchi | 0.0479 | 0.0843 | 是 |
| TN 表层 | 0.0087 | 0.0693 | 是（幅度差异大） |
| TN 中层 | 0.1323 | 0.0983 | 是 |
| TN 底层 | 0.0892 | 0.0890 | 是 |
| TP 表层 | 0.1228 | 0.1249 | 是 |
| TP 中层 | 0.0846 | 0.0576 | 是 |
| TP 底层 | 0.0720 | 0.0447 | 是 |

十项任务方向完全一致，宏平均 ΔR² 两协议接近（0.0884 vs 0.0988）。**但绝对水平不可比**：留站点协议下 M2 宏平均 R² 0.5615，仍低于随机留出下的 0.6398；留站点基线（0.4628）也低于随机留出基线（0.5512）。留站点增益更大的原因不是 M2 在空间上更强，而是基线失去了站内样本的便利。

TN 表层的协议差异需要单独说明：随机留出下三种子均值仅 +0.0087（seed 42 为负），留站点下 +0.0693（区间 [0.0422, 0.1186]）。合理解释是表层 TN 的可预测性大量来自站点内重复采样信息，随机留出时这部分信息已被 M0 使用，垂向特征只能提供边际补充；一旦整站留出，垂向温盐氧浊成为替代性的站点状态描述，增益随之显现。**结论应表述为「TN 表层的增益依赖验证协议」，而非「TN 表层不受益」或「普遍受益」。**

## 6. 局限与不可声称的内容

1. **同期实测输入**：EPD 12 项为测试时点同次采样的原位观测，结论只能是「具备同期垂向环境观测条件下的估计精度提升」，**不是**无现场观测条件下的预报能力，也不是空间外推能力。
2. **留站点阶段只有单一模型种子**（42）。多种子确认只在 Random Strict 上完成；留站点的种子稳健性未检验。
3. **XGBoost 未进入留站点阶段**（方案允许省略以控制工作量）。因此 M2 的跨模型普适性本轮仍未在留站点协议下验证。
4. **站点折来源不完全统一**：Chl-a / TN / TP 使用各自 family v2 冻结折（三族映射经核对为同一套：84 站，17/17/17/17/16，KFold seed 20260921）；Secchi 使用分海区五折留站验证的冻结站点折（94 站，23/22/18/16/15，按海区分层）。两者分层方式不同，Secchi 的留站点数字与其他任务不严格同源。
5. **Random Strict 的事件跨层重叠**：同一采样事件可能同时出现在训练与测试，故其数字不得与正式论文 Station Holdout 表格并列。
6. TP 表层在留站点下整体水平仍低（pooled M2 R² 0.2447）且区间极宽；不得引用为"TP 表层已可预测"。
7. 门槛是预注册的研发投入标准，不是统计显著性检验；Bootstrap 区间仅用于描述抽样不确定性。

## 7. 下一步建议

1. **留站点多种子**：对 Station Holdout 补跑 seed 2026 / 3407（20 次 × 5 折 = 200 次拟合），验证留站点增益的种子稳健性；这是当前唯一未闭合的确认环节。
2. **留站点 XGBoost 对照**：可选，用于确认 M2 的跨模型方向；若与 Random Strict 一致（M2 对树模型为正、差值特征为负），可强化"仅用 12 项原始值"的结论。
3. 若上述两项通过，M2（89 项）可作为后续论文的**候选增强特征方案**，但仍须：以正式 Station Holdout 协议重跑、独立版本目录、显式声明对正式结果的影响范围；本轮不触碰正式 77 特征、正式结果与论文。
4. 不启动 pH、历史水质滞后特征等新方向 —— 按方案要求本轮到此停止。
