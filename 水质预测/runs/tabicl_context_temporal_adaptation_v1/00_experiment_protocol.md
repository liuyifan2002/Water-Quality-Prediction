# TabICLv2 上下文与历史环境特征适配实验协议

本实验为独立的 Random Strict 扩展实验，不修改正式 77 项特征、原始主表、外部测试划分、内部五折划分或既有模型结果。外部划分与内部划分分别使用 `runs/random_10task_v1/01_random_split_manifest.csv` 和 `runs/random_tabular_model_zoo_v2/01_inner_fold_manifest.csv`。执行脚本在运行时校验两份文件的 SHA-256。

十项任务各自沿用 `runs/tabicl_water_quality_adaptation_v1/10_task_best_tabicl_config.csv` 中已经由内部 OOF 锁定的配置。上下文试验只改变当前训练折提供给 TabICLv2 的训练样本，不搜索普通推理参数。C0 使用当前训练折全体样本；C1 对固定的 32 个验证查询逐一取最近的 512 或 1024 个样本；C2 按训练折拟合的八个环境状态聚类选择 1024 个训练样本；C3 对六类来源组的距离等权汇总后取 1024 个；C4 使用 512 个相似样本和 512 个训练折全局代表样本。C1 与同一组 32 个查询上的 C0_32 比较。所有完整验证方案使用同一聚类分组、obs_id 顺序和 64 查询批次；聚类、标准化、填补及上下文均仅由当前训练折拟合或选取。

历史环境特征来自独立逐日源，不使用水质目标值作为时滞输入。每日序列先按完整自然日历重建。HKO 雨量按香港本地自然日记录，候选窗口最晚止于采样日前一天；其 `Trace` 保留为非数值缺失，不把它伪装为精确的零雨量。ERA5 冻结原脚本按 `valid_time` 的日历日聚合，主表只有采样日期而无采样时刻；为保证整日数据在任何可能的采样时刻之前结束，ERA5 窗口保守地止于采样日前第二个 UTC 日。当前 L1 使用该日前第二个 UTC 日的辐射与海温，L2 使用截止同日的 30/90 日辐射、海温均值。候选特征不超过 15 项；已经存在于正式 77 项输入中的同名特征不能重复添加。降雨候选只保留覆盖报告，待确定痕量处理协议后才能进入模型比较。

先在 TN 中层、TN 底层、TP 中层、TP 底层、Chl-a 中层、Secchi 的相同第一内层折开展有限筛选。仅在完整第一折上优于同批次 C0、且具有进一步研究价值的方案进入五折验证。所有方案保留负面结果。五折内部 OOF 决定最终配置；外部测试集不得参与方案选择。若上下文和历史特征均未显示可重复改善，停止扩展搜索并保留上一轮已锁定的基准，不通过外部测试挑选方案。

当前机器实际检测到 RTX 2070 Max-Q 8 GiB；GPU 模型顺序运行。预测输出及运行时指标均写入本目录，不覆盖既有实验文件。
