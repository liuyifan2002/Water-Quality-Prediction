# TabICLv2 十任务解释计算 V2

本实验属于独立扩展实验。目标是先计算十项预登记任务的 P1 单查询模型无关 SHAP 与有样本支持的一维 ALE，再依据数值误差、样本覆盖和历史资格检查判定解释质量。`COMPUTED` 只表示数值结果落盘，不等于解释有效。

V1 的七项 `BLOCKED`、既定误差阈值及历史失败记录保持原样。V2 不把“与历史批量预测未严格等价”当作禁止计算 P1 函数解释的门槛；其结果明确解释的是 P1 单查询函数，而非声称严格复现历史批量预测。

冻结内容：正式 split、77 特征及顺序、预训练 checkpoint、训练上下文、逐折 imputer、float32、目标变换、训练背景与采样规则、Permutation SHAP 的 155 次预算与 16 条背景、ALE 分箱与支持度判据。已完成且定义一致的 V1 结果按哈希复制复用，不重算。

调度顺序为先等待现有 V1 GPU 队列完全退出，再扫描其检查点并串行续算十任务；不同时启动两个 GPU 推理队列。每个任务的核心 SHAP、种子敏感性、按原预算规则追加的样本，以及 ALE 支持审查与最多两条曲线均分别落盘。未达到观测支持标准时登记不足，不人为补足分箱。二维 ALE 不属于本轮十任务必达计算。

结论将在十任务计算结束后另行评估，不提前将任何 `BLOCKED` 改写为通过。
