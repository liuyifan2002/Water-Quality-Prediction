# 主线接管文档导航

这一组文档是“预测精度提升试验项目”接入当前主线时留下的整理材料。为了避免文件太多、名字太杂，建议按下面顺序阅读。

## 先看这 5 份

1. `主线接管报告.md`
   - 先看总判断：哪些成果能继承，哪些不能直接用。
2. `主线接管优先级.md`
   - 看哪些内容现在就值得接入主线。
3. `主线禁止重复清单.md`
   - 看哪些失败路线不要再重跑。
4. `主线数据接入计划.md`
   - 看数据应该怎么并入当前主链。
5. `主线下一轮实验计划.md`
   - 看下一轮正式实验先做什么。

## 表格类文件
