# 环境输入文件规范

## 放置位置

三个正式环境输入文件必须放在：

`data/raw/manual/environment/`

文件名固定为：

- `rainfall_features_2014_2024.csv`
- `tide_features_2014_2024.csv`
- `era5_features_2014_2024.csv`

模板文件位于：

`data/raw/manual/environment/templates/`

## 必需字段

### 1. 降雨文件

必需字段：

- `date`
- `rain_1d`
- `rain_3d`
- `rain_7d`
- `rain_14d`
- `rain_30d`
- `rain_month`

字段含义：

- `rain_1d`：采样日前 1 天降雨量
- `rain_3d`：采样日前 3 天累计降雨量
- `rain_7d`：采样日前 7 天累计降雨量
- `rain_14d`：采样日前 14 天累计降雨量
- `rain_30d`：采样日前 30 天累计降雨量
- `rain_month`：对应月份累计降雨量

### 2. 潮汐文件

必需字段：

- `date`
- `tidal_range`
- `tide_events`
- `tide_high_mean`
- `tide_low_mean`
- `tide_level_mean`

字段含义：

- `tidal_range`：日潮差
- `tide_events`：当天有效潮位事件数
- `tide_high_mean`：日平均高潮位
- `tide_low_mean`：日平均低潮位
- `tide_level_mean`：日平均潮位

### 3. ERA5 文件

必需字段：

- `date`
- `t2m`
- `u10`
- `v10`
- `wind_speed`
- `tcc`
- `ssrd_sum_3d`
- `ssrd_mean_3d`
- `ssrd_sum_7d`
- `ssrd_mean_7d`
- `ssrd_sum_14d`
- `ssrd_mean_14d`
- `sst_mean_3d`
- `sst_max_3d`
- `sst_anom_3d`
- `sst_mean_7d`
- `sst_max_7d`
- `sst_anom_7d`
- `sst_mean_14d`
- `sst_max_14d`
- `sst_anom_14d`

字段含义：

- `t2m`：2 米气温
- `u10`, `v10`：10 米风矢量
- `wind_speed`：风速
- `tcc`：总云量
- `ssrd_*`：下行短波辐射窗口统计
- `sst_*`：海表温度窗口统计和异常量

## 日期格式要求

- `date` 必须使用 `YYYY-MM-DD`
- 必须能被 `pandas.to_datetime()` 正常解析

## 时间范围要求

- 数据应覆盖 `2014-01-01` 到 `2024-12-31`
- 至少应覆盖正式水质样本所在日期范围

## 缺失值规则

- 允许存在局部缺失值
- 不允许整列全空
- 不建议大量连续缺失
- 不允许只有 `date` 一列就作为有效环境输入

## 明确禁止

- 不允许用随机数伪造环境数据
- 不允许用均值、常数、占位值冒充真实环境驱动
- 不允许把空表或只有 `date` 的表当成“环境已接入”

## 环境特征进入主链后的检查方法

1. 运行：

```powershell
python scripts/07_validate_environment_inputs.py --out-dir outputs/modeling/experiments/tmp_env_validation
```

2. 检查：

- `environment_input_validation_report.json`
- `environment_input_field_summary.csv`
- `environment_input_missing_rate.csv`

3. 环境构建后检查：

- `environment_features_2014_2024.csv` 是否除 `date` 外还有字段
- `model_table_3depth_2014_2024.csv` 是否出现 `rain_`、`tide_`、`era5_` 前缀字段

4. 如需完整实验核查，运行：

```powershell
python scripts/07_run_env_feature_check.py --date-tag 20260516
```

如果报告里出现“没有环境字段进入模型”，说明当前仍未完成环境并入。
