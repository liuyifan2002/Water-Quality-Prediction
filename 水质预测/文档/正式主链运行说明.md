# 正式主链运行说明

## 1. 正式主链范围

当前正式主链为：

- 94 站点
- 2014-2024 年
- 三水层（Surface / Middle / Bottom）
- `Chl-a / Secchi / TN / TP`
- `full_station` 主链

## 1.1 正式评价口径

- 每个“指标—水层”任务在其全部有效样本中固定随机抽取 `80%` 作为训练集、`20%` 作为测试集。
- 随机种子固定为 `42`，以保证正式结果可复现。
- 该口径评价同分布留出样本的预测表现，不代表对 2023-2024 或其他未来年份的时间外推能力。
- 已归档的严格时间外推输出仅作历史敏感性对照，位置为 `归档_历史版本/过期输出/严格时间外推_20260516/`。

## 2. 输入与输出

### 主要输入

- 原始水质与站点数据：`数据/原始数据/`
- GEE 导出结果：并入 `数据/处理后数据/正式主表/` 或 `衍生版本/`
- ERA5 / 降雨 / 潮汐 / 夜光特征表

### 主要输出

- 正式主表：`数据/处理后数据/正式主表/`
- 正式结果：`结果/正式结果/full_station/`
- 论文图表：`结果/论文图表/`

## 5. 注意事项

- 正式主结果只能由正式主链脚本生成。
- 论文正文及图表必须称为“随机留出测试”或“随机比例留出”，不得表述为“严格时间外推”或“未来年份预测”。
- 扩展实验不得覆盖正式主表与正式结果目录。
- 如需新实验，请写入 `结果/扩展实验/实验名称_日期/`。
