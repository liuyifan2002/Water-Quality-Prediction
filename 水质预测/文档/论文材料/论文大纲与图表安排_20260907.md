# 论文大纲与图表安排（基于当前结果）

## 一、写作口径

1. 正式主结果为全站点模型在固定随机 80%/20% 留出下的结果，用于任务间的统一比较；不将其表述为跨年份的中长期外推精度。
2. Chl-a、TN 和 TP 按表层、中层、底层构成九项多水层预测任务。透明度（Secchi）是站点—日期尺度的塞氏盘观测，原始表中三层记录完全重复，因此只作为一个站点—日期透明度任务解释；原有三条重复建模结果仅为数据结构下的重复检验，不作为三层独立观测证据。
3. 遥感质量、Chl-a 高值误差和分海区模型均属于扩展诊断。它们用于说明适用条件与局限，不覆盖正式主模型。
4. 年际趋势筛查未做季节调整、多重检验校正和自相关处理，仅作为附录探索结果，不进入核心结论。

## 二、建议论文结构

### 第1章 绪论

**1.1 研究背景与意义**：近岸水质受陆海交换、垂向混合和短时扰动共同影响；站点观测、遥感与过程数据各有优势和缺口。

**1.2 国内外研究进展**：多源水质预测、近岸遥感、垂向水质差异、空间泛化和不确定性诊断。重点指出：现有研究常以单水层、随机验证或单一遥感反演为主，对“遥感何时可用”和“预测在哪些条件下失效”的统一检验不足。

**1.3 研究内容与技术路线**：说明观测级样本、外部驱动接入、四组信息源控制比较、正式模型和扩展诊断的关系。

**1.4 主要工作与创新**：

- 建立站点—日期—水层观测级多源数据架构，保持目标水层、质控与外部数据键值可追溯；
- 以质量记录约束遥感融合，用对照实验回答遥感在何种影像质量条件下才可能产生增益；
- 将正式预测结果与高值误差、空间泛化边界分层报告，避免以单一随机留出 R2 替代复杂近岸条件下的适用性判断。

### 第2章 研究区、数据与水质背景

**2.1 研究区与监测网络**：94 个站点、10 个水区及其陆海环境差异。

**2.2 数据来源与观测级样本**：水质原始记录、站点位置、ERA5、降雨、潮汐、夜间灯光、Landsat 和 Sentinel-2；明确同日其他水质变量仅用于机理分析，不进入预测输入。

**2.3 时空匹配与质量控制**：`sample_id=站点—日期`、`obs_id=站点—日期—水层`；日尺度窗口、月尺度匹配、遥感有效像元与缺失状态。

**2.4 水质时空分异与垂向背景**：按水区、季节和水层展示 Chl-a、TN、TP 的变化；透明度仅按站点—日期和水区季节展示，不作垂向比较。

**2.5 表层观测水质状态**：以盐度、浊度、悬浮物、TIN、正磷酸盐等同日观测变量进行描述性聚类，呈现淡水影响和高浊高营养背景；明确该分析不用于模型输入，也不作因果识别。

### 第3章 多源特征构建与预测方法

**3.1 预测目标与信息边界**：九项多水层目标加一个站点—日期透明度目标；同日其他水质变量不进入模型；目标历史信息仅在与验证设计相容时使用。

**3.2 多源特征构建**：时空基线、历史与过程、遥感、历史—遥感融合四组信息源；ERA5 日尺度窗口、降雨累积、潮汐、夜间灯光和质量标记。

**3.3 正式模型与评价**：XGBoost、`log1p` 变换、固定随机 80%/20% 留出、R2、RMSE、MAE、NSE；将随机留出定位为同分布预测比较。

**3.4 扩展诊断设计**：

- 遥感质量和严格近同日 Sentinel-2 覆盖敏感性；
- Chl-a 高值样本误差与区间覆盖；
- 五折留站点和 2023—2024 年留出验证下的分海区模型比较。

### 第4章 全站点正式预测结果

**4.1 正式随机留出性能**：报告全站点模型的统一对照结果。重点结果为 TN 表层 R2=0.798、TP 表层 R2=0.725、透明度 R2=0.616；Chl-a 三个水层约为 0.374—0.465。

**4.2 特征组贡献与遥感的总体角色**：比较基线、历史与过程、遥感和融合组。强调过程与历史信息贡献更稳定，遥感不是独立替代项。

**4.3 目标与水层差异**：讨论 Chl-a 的短期扰动与垂向不可见性、TN/TP 的过程差异及透明度的观测尺度限制。

**4.4 正式结果小结**：形成后续适用边界分析的基线，不提前使用扩展模型替换主结果。

### 第5章 遥感适用条件、Chl-a 高值误差与空间泛化边界

**5.1 遥感质量条件与光学敏感性**：严格 Sentinel-2 条件下仅覆盖 1,254/10,866 个样本（11.5%）；质量门控相对于历史过程模型的全样本平均 R2 变化仅 +0.0011。将该结果解释为“遥感需在覆盖与质量均充分时再讨论局部增益”，不表述为总体精度突破。

**5.2 Chl-a 高值误差结构**：训练集 P90 以上高值在三个水层均表现出明显低估；以 Chl-a 高值散点、低估比例和绝对误差为主。区间试验用于说明全局校准在高值尾部覆盖不足，而非宣称已解决高值风险。

**5.3 分海区模型的空间泛化边界**：五折留站点中 Chl-a 三层存在稳定局部改善，TN 底层为弱正信号；TN 表中层和 TP 不稳定。2023—2024 年留出中，分海区模型对 Chl-a、透明度和 TP 未呈现正增益，因此不升级为中长期正式主模型。

**5.4 讨论小结**：以“何时可用、何时不应过度解释”为线索，界定正式模型的适用范围和下一步数据缺口。

### 第6章 结论与展望

**6.1 主要结论**：分别归纳数据架构、正式模型结果、遥感质量条件、Chl-a 高值误差和空间泛化边界五项证据。

**6.2 局限与展望**：

- 随机留出不能取代跨年份的中长期外推；
- 中层和底层缺少直接光学观测，且 Chl-a 高值受短期水动力、光照和陆源输入共同扰动；
- 严格 Sentinel-2 覆盖率有限，现有质量比例字段尚需重新定义与验证；
- 后续优先补充采样时刻、近岸水动力、河流径流与更稳定的高质量遥感序列。

## 四、图表使用原则

1. 正文图只放直接支撑结论的图件；同一结论不重复使用三张相似图。
2. 图题和图注中标明验证条件，例如“固定随机留出”或“五折留站点”，避免读者把不同 R2 放在同一口径下比较。
3. 对透明度统一使用“站点—日期透明度”或“Secchi 透明度”表述，不写“透明度表层/中层/底层差异”。
4. Chl-a 高值与空间泛化均为限制性证据，图注和正文采用“误差结构”“适用边界”“局部改善”等表述。
