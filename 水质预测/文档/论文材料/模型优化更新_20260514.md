# 2026-05-14 模型优化更新说明

## 本轮已经落实的优化

1. 去除同期水质协变量
   - 主模型不再使用同日的其他水质指标作为输入。
   - 当前正式设定回到“可解释预测”，避免把同期监测值混入特征后造成不合理高分。

2. 引入历史滞后特征
   - 已加入 `lag1`、`lag2`、`roll3`、`delta1`。
   - 按 `station + depth + date` 构造，不跨站点、不跨水层混用。
   - 当前四个目标变量均已接入各自历史项：
     - `chla_ug_l`
     - `secchi_depth_m`
     - `tn_mg_l`
     - `tp_mg_l`

3. 强化环境驱动特征
   - 已接入气象、降雨、潮汐、夜间灯光等过程变量。
   - 已构造环境交互项：
     - `t2m_x_rain14d`
     - `wind_speed_x_rain14d`
     - `rain14d_x_tidal_range`
     - `t2m_x_tidal_range`
   - 已加入环境滞后特征与滚动特征：
     - `lag1`
     - `lag2`
     - `roll3`
     - `delta1`

4. 目标变量偏态处理
   - 对非负目标值训练时启用 `log1p` 变换。
   - 预测后使用 `expm1` 反变换，并限制预测值不小于 0。

5. 时间感知调参
   - 新增训练集内部时间验证：
     - 外层正式评估仍为 `2014-2022` 训练、`2023-2024` 测试。
     - 内层调参使用训练期内部的时间验证切分，不使用随机验证。
   - 当前已在 `05_train_full_station_models.py` 中加入可选 `--tune` 模式。

## 当前可以得到的研究判断

1. 历史惯性仍然是最稳定的信息来源
   - `f1_history` 的平均表现已经略高于 `f3_history_remote`。
   - 说明在严格时间外推下，历史水质轨迹与过程驱动比遥感单独输入更稳。

2. 遥感不是“无用”，但增益有明显边界
   - 对 `Secchi` 三个水层，遥感融合仍有稳定帮助。
   - 对 `TP middle`，遥感融合也有小幅增益。
   - 对 `Chl-a` 和 `TN`，遥感增益不稳定，说明其对中长期预测的贡献受数据质量与机制表达限制。

3. Chl-a 仍是当前最难目标
   - 即使加入历史、环境、时间调参，`Chl-a` 的 R2 仍明显低于 `TN`、`TP surface`、`Secchi`。
   - 这与藻类受短期光热、风浪、降雨、营养盐输入共同驱动的复杂机制一致。

## 下一步最值得继续做的事

1. 优先强化 `Chl-a surface`
   - 接入更短时间窗的 `ERA5 ssrd/sst` 日尺度窗口特征。
   - 强化高质量近同日遥感匹配。

2. 优化遥感使用方式
   - 重点保留质量更稳定的 Landsat 特征。
   - 对 Sentinel-2 做更严格有效像元筛选，减少低质量样本噪声。

3. 开展分海区建模
   - 94 站点整体建模已证明可行。
   - 下一步可作为正式扩展实验，比较“全域统一模型”和“分海区模型”的差异。

4. 继续补做空间外推与连续制图联动
   - 让模型评价从“时间外推”进一步扩展到“空间泛化能力”。
   - 为后续连续空间制图提供更稳的论文落脚点。
