# 去同期水质协变量后的时间外推结果摘要

## 任务设定

- 样本定义：`obs_id = 站点 × 日期 × 水层`
- 时间划分：`2014-2022` 训练，`2023-2024` 测试
- 目标变量：`Chl-a / Secchi / TN / TP`
- 水层：`surface / middle / bottom`

## 这次改了什么

当前正式主链已去掉“同期其他水质指标”作为输入，不再使用：

- 同日 `TN / TP / Secchi / Chl-a` 之间的互相回归
- 同日温盐氧等水质协变量作为主预测输入

当前保留的正式特征组为：

### baseline

`lon, lat, year_offset, month_sin, month_cos, is_wet_season, quarter, day_of_year, water_zone_code`

### f1_history

`baseline + days_since_prev_sample + 当前目标变量自身历史`

历史特征格式为：

- `target_lag1`
- `target_lag2`
- `target_roll3`
- `target_delta1`

### f2_remote

Landsat + Sentinel-2 光谱、指数、有效像元/影像数量与可用性特征

### f3_history_remote

`f1_history + f2_remote`

## 当前最重要的结果

### 平均表现

| 特征组 | mean R2 |
| --- | ---: |
| f3_history_remote | 0.2780 |
| f1_history | 0.2570 |
| baseline | 0.2147 |
| f2_remote | 0.0175 |

解释：

- 历史滞后特征确实带来了稳定提升。
- 遥感单独建模仍然较弱。
- 遥感与历史结合后，整体优于仅历史，但提升幅度不算特别大。

## 现在可以怎样解释

### Chl-a

- 当前终于回到更可信的量级。
- 表中 `R2 ≈ 0.18-0.23` 对 Chl-a 来说，属于“有一定可预测性，但仍较难”的结果。
- 这比之前 `R2 > 0.6` 那类使用同期水质协变量的结果更可信。

### TN

- TN-surface 仍然是当前最好做的变量之一，`R2 = 0.4927`。
- 说明 TN 的时间惯性和历史延续性比较明显。

### TP

- TP-surface 还能维持 `R2 = 0.4374`。
- 但中下层 TP 仍然偏弱，说明 TP 的垂向机制和事件驱动更复杂。

### Secchi

- Secchi 三层都比较稳，`R2 ≈ 0.35-0.39`。
- 说明透明度受季节-空间背景与历史状态共同控制，遥感加入后也有一定帮助。

## 当前最值得保留的科研判断

1. 去掉同期水质协变量后，模型结果明显回落，但科学解释显著变得可信。
2. 历史滞后特征是当前主提升来源，说明本研究确实存在时间记忆结构。
3. 遥感单独作用有限，但和历史信息结合后对多指标有小幅增益。
4. Sentinel-2 质量瓶颈仍然明显，后续提升重点仍应放在高质量遥感样本与更优匹配策略。

## 当前正式推荐结果

若作为本研究当前阶段的正式时间外推主结果，建议优先报告：

- Chl-a：`f3_history_remote`
- Secchi：`f3_history_remote`
- TN：`f3_history_remote`
- TP：surface 用 `f1_history`，middle/bottom 可同时报告 `f3_history_remote` 与 `f1_history` 对比
