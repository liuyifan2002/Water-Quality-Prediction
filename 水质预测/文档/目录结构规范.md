# 目录结构规范

## 1. 顶层目录

```text
配置/
数据/
脚本/
结果/
文档/
归档_历史版本/
待确认_未归类/
```

## 2. 目录职责

### 配置

- 放路径、年份、正式主链和历史配置
- 不放结果、不放论文材料

### 数据

- `原始数据/`：原始输入和原始下载
- `中间数据/`：中间过程数据
- `处理后数据/正式主表/`：正式主链稳定输入
- `处理后数据/衍生版本/`：增强版、敏感性版、实验版
- `处理后数据/诊断数据/`：诊断专用数据
- `外部数据/`：外部辅助数据

### 脚本

- `01_数据准备/`：样本与基础表
- `02_特征构建/`：环境特征、遥感 merge、主表构建
- `03_GEE遥感导出/`：GEE JS
- `04_模型训练/`：训练脚本
- `05_诊断分析/`：诊断脚本
- `06_结果汇总与绘图/`：汇总、绘图、SHAP、PPT
- `历史版本/`：旧脚本留档

### 结果

- `正式结果/`：正式主链输出
- `扩展实验/`：扩展实验输出
- `诊断结果/`：诊断分析输出
- `论文图表/`：论文主图和 SHAP 图
- `PPT材料/`：演示资产

### 文档

- 项目规则、运行说明、迁移记录、重构计划
- `论文材料/`：论文解读与写作材料

### 归档与待确认

- `归档_历史版本/`：过期输出、历史杂项
- `待确认_未归类/`：不确定归属内容

## 3. 新增文件放置规则

新增前必须先判断属于：

1. 正式主链
2. 扩展实验
3. 诊断分析
4. 论文输出
5. 历史留档
6. 待确认

不能判断时，先放 `待确认_未归类/`。

## 4. 不允许的混放

- 不允许把正式结果和扩展实验结果混放
- 不允许把论文文稿和结果 CSV 混放
- 不允许把 GEE 脚本和正式训练脚本混放
- 不允许把历史脚本和正式主链脚本混放

## 5. 命名约束

- 脚本：`编号_英文功能.py`
- 配置：中文说明性名称 + `.json`
- 结果目录：使用稳定名称，避免“最终版”“修改版”“新版本”这类口语命名
- 实验目录：建议 `实验名称_日期`
