# 项目架构说明

## 1. 项目目标

本项目面向香港近岸水质预测与遥感敏感性分析，构建一条从原始监测数据、遥感导出、环境驱动特征，到正式建模、结果汇总、论文图版和诊断分析的完整工作链。

当前正式主链为：**全站点三水层 `full_station` 主链**。

## 2. 总体结构

```text
数据输入 -> 数据准备 -> 特征构建 -> 建模总表 -> 模型训练 -> 结果汇总 -> 图表/论文材料
```

## 3. 正式主链模块

### 3.1 数据准备

- 目录：`脚本/01_数据准备/`
- 作用：
  - 站点样本整理
  - 水质主表构建

### 3.2 特征构建

- 目录：`脚本/02_特征构建/`
- 作用：
  - GEE 导出结果合并
  - ERA5、降雨、潮汐、夜光特征准备
  - 三水层建模主表构建

### 3.3 遥感导出

- 目录：`脚本/03_GEE遥感导出/`
- 作用：
  - Sentinel-2、Landsat、VIIRS GEE 导出脚本管理

### 3.4 模型训练

- 目录：`脚本/04_模型训练/`
- 作用：
  - 正式主链训练
  - 扩展实验训练

### 3.5 诊断分析

- 目录：`脚本/05_诊断分析/`
- 作用：
  - `Chl-a surface` 峰值、自相关、残差、覆盖率等诊断

### 3.6 结果汇总与绘图

- 目录：`脚本/06_结果汇总与绘图/`
- 作用：
  - 正式结果表
  - 论文图
  - SHAP
  - PPT 输出

## 4. 结果分层

- `结果/正式结果/`
  - 正式主链最终结果
- `结果/扩展实验/`
  - 站点独立建模、分海区建模、Chl-a 优化等
- `结果/诊断结果/`
  - 诊断报告与诊断图
- `结果/论文图表/`
  - 论文主图、SHAP 图
- `结果/PPT材料/`
  - 演示图和 PPT 文件

## 5. 文档分层

- `文档/`
  - 结构说明、运行说明、迁移记录、重构计划
- `文档/论文材料/`
  - 结果解读提纲、研究意义、论文草稿支撑材料

## 6. 历史内容管理

- 旧脚本：`脚本/历史版本/`
- 过期结果：`归档_历史版本/过期输出/`
- 归属不清：`待确认_未归类/`

## 7. 当前整理原则

本轮整理仅处理：

- 目录重组
- 路径修复
- 说明文档补齐

本轮**不处理**：

- 模型算法修改
- 特征逻辑修改
- 绘图风格修改
- 结果数值重定义
