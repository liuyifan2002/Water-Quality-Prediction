# 香港近岸水质预测项目目前进度报告

> 修正说明：本报告前半部分记录的是 pooled 总模型阶段结果，即把 8 个站点合并训练一个总体模型。根据后续研究设定，站点预测应进一步采用“站点独立建模”。站点独立建模结果已补充在 `reports/站点独立建模补充报告.md`。后续报告中，pooled 模型应作为总体基线，station-specific 模型作为主分析线。

## 3. 数据处理流程

| 数据源 | 当前处理方式 | 处理目的 | 对结果的影响 |
|---|---|---|---|
| EPD Historical Marine Water Quality Data | 合并 2014-2024 年数据，筛选 8 个站点和表层样本，统一字段为 `Chl_a`、`SD`、`TN`、`TP` | 建立实测水质基准 | 得到 1038 条表层样本；`Chl_a`、`SD` 无缺失，`TN`、`TP` 各有少量缺失 |
| ERA5 single levels | 使用 CDS ERA5 time-series 入口提取香港中心点小时数据，聚合为月均 `t2m`、`u10`、`v10`、`tcc` | 表达气温、风场、云量等过程驱动因子 | 气象特征完整接入；当前是中心点近似，后续可升级为区域平均 |
| HKO 降水 | 下载 HKO 日降水，按采样日期计算 `rain_3d`、`rain_14d`、`rain_month` | 表达短期和月尺度降水径流影响 | 增强过程模型对透明度、营养盐输入的表达 |
| HKO 潮汐 | 使用 Quarry Bay HLT 潮汐表，计算采样日 `tidal_range` | 在缺少采样具体时刻时，用日潮差表示水动力强弱 | 提供潮汐过程的一阶近似 |
| VIIRS 夜光 | GEE 提取站点缓冲区月均 `ntl_avg_rad` 和 `ntl_cf_cvg` | 表达人类活动、岸线开发和陆源压力代理 | 作为过程/人类活动特征进入 F1 和 F3 |
| Landsat 8/9 | GEE 提取月尺度波段，计算指数，进行缺失处理并保留质量标记 | 表达水色、浊度、透明度和近岸水体状态 | 质量处理后显著增加可用样本，融合模型表现改善 |

## 4. Landsat 缺失情况、影响与补齐方法

### 4.1 原始缺失情况

原始 Landsat 月尺度特征共 1038 条站点-月份记录。由于云、云影、近岸水体掩膜和有效像元不足等原因，部分月份波段为空。

| 项目 | 数值 |
|---|---:|
| Landsat 总记录数 | 1038 |
| 任一核心波段缺失的记录数 | 280 |
| `valid_count = 0` 的记录数 | 22 |
| 核心波段原始缺失率 | 27.0% |

按站点统计，缺失率如下：

| 站点 | Landsat 缺失率 |
|---|---:|
| DM1 | 42.1% |
| NM3 | 37.9% |
| PM7 | 27.3% |
| MM8 | 27.2% |
| VM5 | 25.8% |
| TM4 | 22.8% |
| WM2 | 17.4% |
| SM6 | 15.9% |

按年份看，2014、2018、2019 年缺失偏高：

| 年份 | 缺失率 |
|---|---:|
| 2014 | 41.7% |
| 2015 | 33.3% |
| 2016 | 20.8% |
| 2017 | 22.9% |
| 2018 | 40.6% |
| 2019 | 37.5% |
| 2020 | 27.7% |
| 2021 | 23.7% |
| 2022 | 16.0% |
| 2023 | 12.5% |
| 2024 | 19.8% |

### 4.2 Landsat 缺失对模型的影响

Landsat 缺失会直接影响 F2 遥感模型和 F3 融合模型。

在未处理 Landsat 缺失时，模型只能使用有完整遥感特征的样本，导致 Chl-a 可用样本减少：

| 阶段 | 训练样本 | 测试样本 | Chl-a F3 R² |
|---|---:|---:|---:|
| Landsat 原始缺失未补齐 | 597 | 161 | -0.204 |
| Landsat 补齐并加入质量标记后 | 846 | 192 | -0.017 |

这说明 Landsat 缺失不是简单的数据完整性问题，而是会改变 F1/F2/F3 消融实验的结论。如果不处理缺失，融合模型会被遥感缺失和样本减少拖累。

### 4.3 当前采用的补齐方法

当前没有直接删除缺失样本，而是采取“补齐 + 标记”的保守策略。

| 步骤 | 方法 | 说明 |
|---|---|---|
| 1 | 补算指数 | 由 `blue`、`green`、`red`、`nir`、`swir1`、`swir2` 重新计算 `ndvi`、`ndwi`、`mndwi`、`ndti` |
| 2 | 质量标记 | 新增 `landsat_missing`、`landsat_imputed`、`landsat_no_data` |
| 3 | 时间插值 | 对同一站点的月尺度时间序列进行短缺口线性插值，最多补 2 个月连续缺口 |
| 4 | 气候态兜底 | 剩余缺口依次使用站点-月份中位数、月份中位数、全局中位数补齐 |
| 5 | 保留补齐信息 | 模型输入中保留质量标记，避免模型把补充值当作完全等价的原始观测值 |

### 4.4 补齐效果

| 特征类型 | 原始缺失率 | 插值后缺失率 | 最终缺失率 |
|---|---:|---:|---:|
| Blue | 27.0% | 0.2% | 0.0% |
| Green | 27.0% | 0.2% | 0.0% |
| Red | 27.0% | 0.2% | 0.0% |
| NIR | 27.0% | 0.2% | 0.0% |
| SWIR1 | 27.0% | 0.2% | 0.0% |
| SWIR2 | 27.0% | 0.2% | 0.0% |
| NDVI | 27.0% | 0.2% | 0.0% |
| NDWI | 27.0% | 0.2% | 0.0% |
| MNDWI | 27.0% | 0.2% | 0.0% |
| NDTI | 27.0% | 0.2% | 0.0% |

补齐后的直接效果是：

- Chl-a 融合模型可用样本从 `597/161` 提升到 `846/192`。
- Chl-a F3 模型 R² 从 `-0.204` 改善到 `-0.017`。
- F3 融合模型开始优于原始状态下的 F1/F2 对比结果。

## 5. 三类模型的输入变量与考虑因素

当前实验采用三类模型进行消融：

- F1：过程模型
- F2：遥感模型
- F3：融合模型

### 5.1 v0 阶段模型输入

| 模型 | 输入变量数量 | 输入因素 | 具体变量 |
|---|---:|---|---|
| F1 过程模型 | 10 | 季节、气象、降水、潮汐、人类活动代理 | `month`, `t2m`, `u10`, `v10`, `tcc`, `rain_3d`, `rain_14d`, `rain_month`, `tidal_range`, `ntl_avg_rad` |
| F2 遥感模型 | 13 | Landsat 波段、指数、质量标记 | `blue`, `green`, `red`, `nir`, `swir1`, `swir2`, `ndwi`, `mndwi`, `ndti`, `valid_count`, `landsat_missing`, `landsat_imputed`, `landsat_no_data` |
| F3 融合模型 | 23 | F1 + F2 | 过程变量 + 遥感变量 |

### 5.2 优化阶段模型输入

优化阶段在 v0 基础上增加季节周期、风场派生、遥感比值、滞后/滑动平均和空间特征。

| 模型 | 最终输入量 | 考虑因素 | 变量组成 |
|---|---:|---|---|
| F1 过程模型 | 46 | 空间差异、季节周期、气象、风场、降水、潮汐、夜光、过程滞后 | `lon`, `lat`, 8 个站点 one-hot，`month`, `season_sin`, `season_cos`, `t2m`, `u10`, `v10`, `tcc`, `wind_speed`, `wind_dir_sin`, `wind_dir_cos`, `rain_3d`, `rain_14d`, `rain_month`, `tidal_range`, `ntl_avg_rad`，以及过程变量的 `lag1`, `lag2`, `roll3` |
| F2 遥感模型 | 41 | 空间差异、Landsat 波段、遥感指数、波段比值、遥感质量、遥感滞后 | `lon`, `lat`, 8 个站点 one-hot，`blue`, `green`, `red`, `nir`, `swir1`, `swir2`, `ndvi`, `ndwi`, `mndwi`, `ndti`, `blue_green`, `green_red`, `red_green`, `nir_red`, `red_nir`, `valid_count`, `landsat_missing`, `landsat_imputed`, `landsat_no_data`，以及遥感指数/质量的 `lag1`, `lag2`, `roll3` |
| F3 融合模型 | 77 | F1 + F2，多源融合 | 过程变量、遥感变量、空间变量、滞后变量、质量标记全部进入模型 |

### 5.3 新增特征的意义

| 新增特征类型 | 代表变量 | 作用 |
|---|---|---|
| 季节周期 | `season_sin`, `season_cos` | 避免直接使用月份造成 12 月到 1 月的断点，表达周期性 |
| 风场派生 | `wind_speed`, `wind_dir_sin`, `wind_dir_cos` | 表达风致混合、输运和再悬浮过程 |
| 滞后和平滑 | `lag1`, `lag2`, `roll3` | 表达水质对气象、降水、遥感状态的滞后响应 |
| 遥感比值 | `blue_green`, `green_red`, `red_green`, `nir_red`, `red_nir` | 补充水色、浊度、透明度和叶绿素相关代理信息 |
| 空间差异 | `lon`, `lat`, `station one-hot` | 表达不同站点、水区和岸线条件差异 |
| 目标变换 | `log1p(Chl_a)`, `log1p(TN)`, `log1p(TP)` | 减弱右偏分布和极值对模型的影响 |

## 8. 阶段性结论

1. 目前已完成从数据整理、多源特征构建、Landsat 缺失处理、F1/F2/F3 消融到四目标优化建模的完整流程。
2. Landsat 缺失处理是关键步骤。原始缺失率约 27.0%，若不处理会显著减少模型可用样本，并影响融合模型结论。
3. 补齐 Landsat 后，Chl-a 可用训练/测试样本从 `597/161` 增加到 `846/192`，融合模型表现明显改善。
4. 第一轮特征优化后，四个目标变量的 R² 均明显提升，其中 TN 和 TP 提升最显著。
5. Chl-a 虽然已有改善，但最优模型目前是 F1 过程模型，说明当前 Landsat 特征对 Chl-a 的增益仍有限。后续应重点加强 Chl-a 的生态滞后、温盐过程、潮汐过程和 Sentinel-2 红边遥感信息。
6. SD、TN、TP 已经形成较稳定的预测结果，可以作为当前阶段成果的主要展示对象；Chl-a 适合作为后续重点攻克对象。
